## Reporting a Vulnerability

If you discover a security vulnerability within **Adhkar**, please report it responsibly:

### How to Report
- 📧 **Email**: Send vulnerability details directly to **[shaikkabeerahmed786@gmail.com](mailto:shaikkabeerahmed786@gmail.com)**.
- 🔒 **GitHub Security Advisory**: You may also submit a private report via the [GitHub Security Advisory](https://github.com/Kabeer786786/adhkar/security/advisories/new) feature if enabled on the repository.

### What to Include
To help us investigate and address the issue quickly, please provide:
1. A summary of the vulnerability and its potential security impact.
2. Step-by-step instructions or proof-of-concept to reproduce the vulnerability.
3. The app version and operating system (Android version, iOS version).

### What to Expect
- **Response Time**: You will receive an initial acknowledgement within **48 hours**.
- **Fix Timeline**: We aim to evaluate, patch, and release a security fix as promptly as possible.
- **Disclosure**: We kindly ask that you keep the issue confidential until a fix has been published.

Thank you for helping keep Adhkar secure and privacy-conscious for all users!
